Why SolvAm?

Deterministic Equivalence

Combines multimodal vision with deterministic Python SymPy Algebraic Syntax Tree (AST) validation. Eliminates hallucinated roots.

"Red-Pen" Grader

Students solve problems on paper. SolvAm scans their sequential handwritten work and isolates the exact line where mathematical equivalence broke.

WAEC M1/A1 Marks

Grades using official marking rubrics: Method Marks (M1) and Accuracy Marks (A1), teaching students how examiners award partial credit.

Mobile QR Camera Lens

Scan a QR code from any smartphone to pair the phone camera with the desktop workspace in real-time using Native Server-Sent Events (SSE).

Parametric Twins

Generates infinite verified practice questions with guaranteed clean integer roots using the parametric question engine.

Offline-First Resilience

Graceful circuit breakers fail over automatically from Turso Cloud to local SQLite (file:local.db) and remote Meta AI to local SymPy.

How to Replicate & Run the Repository

1

Clone the Repository

Clone the source repository and navigate into the root project directory:

# Clone project
git clone https://github.com/your-username/SolveAm.git
cd SolveAm
2

Install Monorepo Dependencies

Install all workspace packages (Next.js 15, Turborepo, shared types, KaTeX, etc.) at the monorepo root:

npm install
3

Configure the Python Symbolic CAS Engine

Create an isolated virtual environment for the deterministic FastAPI/SymPy microservice:

Windows (PowerShell) 
cd services/symbolic-engine
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
cd ../..

On macOS/Linux, run: python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt && cd ../..

4

Set Up Environment Variables

Duplicate the documented example environment file in apps/web:

cp apps/web/.env.example apps/web/.env.local
Zero-Configuration Ready: SolvAm has baked-in production fallbacks. Even with completely blank keys in .env.local, the app will execute with full local SQLite storage, 50 guest credits, and local SymPy step solving!

If you have live credentials, fill in apps/web/.env.local:

# 1. Clerk Authentication
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_...
CLERK_SECRET_KEY=sk_test_...

# 2. Turso Database (Defaults to local SQLite 'file:local.db' if empty or offline)
TURSO_DATABASE_URL="file:local.db"
TURSO_AUTH_TOKEN=

# 3. Deterministic Symbolic Engine
SYMBOLIC_ENGINE_URL="http://localhost:8000"
NEXT_PUBLIC_SYMBOLIC_ENGINE_URL="http://localhost:8000"

# 4. Meta AI Model API
META_API_KEY=
META_API_URL="https://api.meta.ai/v1/chat/completions"
5

Start the Application

Open two terminal windows from the repository root:

Terminal 1: Start the Python Deterministic Symbolic Engine (Port 8000)

npm run dev:symbolic

Terminal 2: Start the Next.js Web App via Turborepo (Port 3000)

npm run dev

Turborepo will topologically build @solvam/shared-types and boot Next.js on http://localhost:3000 (listening on 0.0.0.0 so phones can connect over Wi-Fi).

6

Connect Your Phone Camera (QR Bridge)

1. Open http://localhost:3000 in your browser.
2. Ensure your phone and PC are on the same Wi-Fi or mobile hotspot.
3. Click "Scan with Phone (QR)". The QR code automatically resolves your PC's LAN IP (e.g. http://192.168.x.x:3000/capture?session=...).
4. Snap your handwritten equation on paper and watch it beam to your desktop screen in real-time.

Production Build Verification

Verify strict TypeScript compilation, linting, and Next.js optimization across the monorepo:

npm run build
